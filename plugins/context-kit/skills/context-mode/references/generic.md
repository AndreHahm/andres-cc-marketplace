# Generic Posture (every mode)

The mode tunes how to move through this repo's governance. `CLAUDE.md` and `.claude/rules/` always
apply and outrank this text.

- A mode is a coarse default posture. Per-action confirmations stay in the skills that own the action.
- Use `AskUserQuestion` for any choice or proceed gate, one decision at a time.
- Make the smallest change that satisfies the request. Read a file before modifying it.
- Commit messages: a subject line plus a short WHY of at most 5 lines, no bulleted changelog body.
- Never silently override an earlier decision, skip a documented phase, or change existing behavior.
  Say what changed and why.
- End with the next actionable step, including any gate or check that still has to run.
