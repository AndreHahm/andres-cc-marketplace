# docs/config: .codacy.yml and docs still describe plugin-root scripts/references/assets as unmirrored after #446

## Summary
The #446 change mirrors plugin-root `references/` and `assets/` for every registered plugin, and `scripts/` for the plugins in the new `scripts_mirrors` registry field, flat into `.claude/references/`, `.claude/assets/` and `.claude/scripts/`. Config and docs written before it still say otherwise, and `.codacy.yml` does not exclude the new generated trees.

## Environment
- **Product/Service**: Claude Code plugin marketplace (`andres-cc-marketplace`)
- **Region/Version**: branch `feat/mirror-plugin-root-shared-folders`, commit `5140d512`; `scripts_mirrors` in `.claude/marketplace-sync.json` lists plugin-devkit, git-kit, analysis-kit, session-kit, workmanagement-kit, context-kit

## Reproduction Steps
1. Open each file listed under Actual Behavior at the stated location.
2. Compare its wording with `.claude/marketplace-sync.json` (`scripts_mirrors`) and `scripts/marketplace_ci/sync_plan.py` (`COMPONENT_DIRS` now includes `references` and `assets`).

## Expected Behavior
Config and docs describe the mirror as it now works: generated trees are excluded from duplicate static analysis, and no document tells a reader that these folders are unmirrored or must be hand-copied.

## Actual Behavior
All locations below were checked by grep during the #446 work.
- **`.codacy.yml`:** the comment at line 71 names only `.claude/skills|agents|commands|hooks|rules` as the generated mirror tree, and `exclude_paths` (lines 125-129) lists those five globs but not `.claude/scripts/**`, `.claude/references/**` or `.claude/assets/**`. The comment says the exclusion exists to stop Codacy flagging the same code a second time under the mirror path (it cites PR #306). Tracked-file counts: 41 script files from the six opted-in plugins now sit under `.claude/scripts/`, plus 7 files under `.claude/references/`. Not verified: what Codacy currently reports for them.
- **`.claude/hooks/README.md` line 49:** "This is deliberately **not** a general `plugins/*/scripts/` mirror" in the `_external-scripts/` section.
- **`scripts/marketplace_ci/prefix_check.py`:** the docstring (around line 17) says `references/`, and `assets/` are "never mirrored into .claude/ at all"; the comment around lines 68-72 repeats the claim.
- **`plugins/plugin-devkit/skills/plugin-rulebook/references/component-file-prefix.md`:** its exclusion-list prose about mirrored directories predates the change.
- **`plugins/analysis-kit/references/anls-report-discovery-convention.md` line 6:** tells the reader to hand-copy any edit into `.claude/references/`, which is now generated by sync.

## Additional Context
- Fixing the plugin-side files means editing plugin components: a plugin-rulebook pass applies, and the `.claude/` mirror of each edited file is regenerated by the post-edit hook.
- Per `CLAUDE.md`, `.codacy.yml`'s `exclude_paths` can only exclude a whole file from a whole engine. Excluding generated mirror trees fits that, but check the effect against Codacy's real issue count after pushing rather than assuming it.
- **Overlap, stated plainly:** #449 also lists the `.claude/hooks/README.md`, `prefix_check.py` and `sync.py` comment items among its stale-text decisions. This issue is the narrower doc/config sweep and adds the `.codacy.yml`, `component-file-prefix.md` and `anls-report-discovery-convention.md` items. Whoever fixes first should close or trim the other.
