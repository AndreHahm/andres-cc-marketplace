# widget-tools

Utilities for creating widget configuration files.

## Installation

```bash
/plugin install widget-tools@test-marketplace
```

## Skills

| Name | Purpose |
|---|---|
| `hello-skill` | Create a new widget configuration file from a name and type |
| `goodbye-skill` | Validate an existing widget configuration file against the widget schema |

## Known Issues

- Widget names containing spaces are not currently supported.
