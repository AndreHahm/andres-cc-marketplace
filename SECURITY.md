# Security Policy

> This marketplace is still in conception and development (pre-1.0). There is no formal
> per-version support matrix yet — security fixes land on `main`.

## Supported Versions

Only the latest state of `main` is supported with security fixes at this time.

## Reporting a Vulnerability

Please report security vulnerabilities privately using GitHub's
[private vulnerability reporting](https://github.com/AndreHahm/andres-cc-marketplace/security/advisories/new)
feature (repository **Security** tab → **Report a vulnerability**), rather than opening a public
issue.

We aim to acknowledge reports within a reasonable timeframe and will keep you updated as the
report is triaged and, if accepted, fixed. Please include enough detail to reproduce the issue
(affected plugin/skill/agent/hook, steps, and impact).
