# Compact Rule Checklist

Mechanical pattern → violation → severity reference for all 33 currently-enabled rules (R1-R10, R13, R14,
R17-R37; R11/R12/R15/R16 disabled per `assets/settings.json`). No narrative rationale, examples, or
"why enable" content — read `SKILL.md` instead for that. Kept in sync with `assets/settings.json` and
`SKILL.md`'s own Active Rules section; any threshold shown here must match those two files exactly (R20).

**Tier key:** `M` = mechanical (pattern/threshold match, safe for a faster model per this rule's own
documented risk profile) · `J` = judgment-heavy (requires contextual reasoning — always run at full
model quality regardless of dispatch mode).

**Forward-looking scope** (R28-R30, R34-R37 and the R9/R14 extensions): a component is "newly-created or
structurally-modified" when the change under review adds, renames, splits or merges it, or edits its
`SKILL.md`, frontmatter, `references/` or `scripts/` — read `git diff <base>...HEAD` when a base is known.
With no change in view (an agent without Bash cannot read the diff), never raise a blocking FAIL for these rules:
report such a finding as ADVISORY tagged `(forward-looking, no change in view)`, and raise a FAIL only when the
caller supplied the changed paths or said to treat the component as modified.

**Unverifiable checks:** a rule whose check needs a tool you do not have (R37's `git ls-files -s` and R31's
`check_evals.py` need Bash) is reported `unverified`, never PASS. So is R31's registry-completeness clause unless the caller supplies the skill's `evals/<skill>/` path: that directory is outside the plugin root this agent enumerates, so never skip it silently.

## R19/R20 Procedure Reminder (always full-quality, never skipped in Fast path)

1. Resolve the canonical absolute path of the target component first. If it resolves to 2+ directories, compare contents — halt and FAIL before continuing if they differ (except the documented `.claude/` mirror exception).
2. When a canonical value in this check touches something else's stated fact (an enum, a threshold), grep the plugin tree for the previous value before closing out — this is R20's job regardless of which mode dispatched this check.

## R18 Consolidation Rule

When 3 or more code blocks in the same component are Weak Warnings (11-20 lines), emit one consolidated ADVISORY ("N blocks exceed 10 lines; consider extracting the largest (M lines)") rather than one entry per block; a block over 20 lines (Warning) or over 30 (Critical) is always reported individually at its own tier.
